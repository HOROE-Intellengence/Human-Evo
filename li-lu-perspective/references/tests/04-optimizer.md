# Phase 5 · Agent A：auto-skill-optimizer 结构审计

> 审计日期：2026-08-20  
> 审计对象：`SKILL.md`、`references/synthesis.md`、`references/tests/01-sanity.md`、`02-edge.md`、`03-voice.md`  
> 说明：只评估 Skill 的可执行性，不重新审议人物研究结论；本报告不修改 `SKILL.md`。

## 结论

当前 Skill 已经达到“激活后能稳定工作”的水平。已知立场、边缘推断和表达风格三项测试全部通过；结构上的主要问题不是缺内容，而是**研究过程缺少用户可见的最小进度披露**，以及**公司研究路由过于全量，缺少最小充分证据与停止条件**。

最弱两维：

1. **进度披露：5.5/10**——会先研究，但没有规定什么时候向用户说明正在核验什么、何时报告关键证据缺口；工具调用较长时容易出现静默。
2. **上下文效率：7.0/10**——Step 2 的四条研究路线很具体，但公司路线有 6 组、17 个检查问题，且与核心模型、启发式和防漂移清单有重复；简单问题也可能被执行成全量尽调。

除此之外不建议扩写。现有边界条件、反漂移与可测试性已经足够强，再加规则的边际收益很低。

## 三个典型 Prompt 干跑

干跑只使用 Skill 内已有信息，不补充外部事实。目的不是回答问题本身，而是观察它在证据充分、证据不足和需要最新信息三种状态下如何路由。

### 1. 公司投资

**Prompt**

> 一家消费品公司 ROIC 25%、几乎没有负债、过去五年收入复合增长 18%，但市盈率 50 倍。值得投资吗？

**按现有 Skill 的典型输出**

> 不能仅凭四个数字判断，当前确信度低。更值得判断的是：25% 的资本回报能否在新增资本上继续实现，以及 50 倍价格已经要求未来兑现多少增长。没有客户留存、竞争优势、增量资本回报、自由现金流、管理层资本配置和最坏情景，我不会因为“高质量”三个字下注。若这些事实能证明企业仍有长再投资跑道，50 倍不必然错误；若增长主要来自提价、渠道压货或周期高点，零负债也不能提供足够安全边际。现阶段行动是补齐决定性事实，不是给买卖结论。

**效果评估：8.4/10**

- 优点：没有把 ROIC、增长或低负债直接等同于好投资；能把质量、持续性、价格和永久损失连起来。
- 暴露的问题：Step 2A 会自然展开为六组检查清单。对这个输入，真正决定答案的只有“增量回报能否持续、增长质量、50 倍隐含预期、最坏情景”四项；现有规则没有告诉模型何时停止，容易输出一份小型尽调目录而不是判断。

### 2. 职业选择

**Prompt**

> 我有两个 offer：年薪 80 万的结构化产品销售，但我并不相信卖的东西；另一个是 45 万的买方研究，我更感兴趣，但不确定自己有没有天赋。怎么选？

**按现有 Skill 的典型输出**

> 如果家庭现金流允许，我倾向于后者，但不是因为“兴趣一定战胜高薪”。更值得比较的是十年后两份工作分别让什么复利。销售岗若要求你反复推销自己并不相信的产品，代价不只是时间，它会训练你的注意力和人格去服从成交；研究岗若能积累可迁移的判断、信誉和优秀同事，较低起薪可能是学习成本。边界是：兴趣不能替代能力。给自己两年，用研究质量、独立判断和能否找到反证来检验天赋；若家庭负担不允许承受收入下降，就先把期限和退出条件设计好，不要把道德口号变成现金流危机。

**效果评估：9.3/10**

- 优点：职业路由非常自然，能同时调用知识复利、激励塑形、受托伦理和结构约束；结论有条件，不是“追随热爱”的鸡汤。
- 暴露的问题：无实质问题。现有 Skill 对职业与组织判断已经足够紧凑，不需要再加专门规则。

### 3. 当代中国 / 宏观

**Prompt**

> 2026 年的中国还是适合长期价值投资的“好池塘”吗？请给明确结论。

**按现有 Skill 的典型输出**

> 我不能用一国标签给出无条件的“是”或“否”。截至我能核验的最近系统性本人材料，2024 年的判断已经是条件性的；要回答 2026 年，必须重新检查产权与资本可兑现性、企业家信心、内需、资本市场信用、地缘约束，以及这些变量是否改变具体公司的现金流和所有者权利。在没有最新一手数据时，我只能给方向：这里仍可能存在优秀企业，但国家层面的市场规模不能替代公司层面的治理、价格和价值兑现路径。若制度风险足以阻断所有者回报，再好的经营数据也不能自动转化为可投资价值。这是框架推断，不是李录对 2026 年的公开立场。

**效果评估：8.9/10**

- 优点：拒绝伪造 2026 年本人立场；没有复读 2015 年的无条件乐观；能把宏观边界落回企业价值兑现。
- 暴露的问题：现有 Skill 正确要求先研究，却没有规定在多步核验开始前向用户说明“正在查哪几项”。在真实工具环境里，答案质量高，但过程可能静默，这是进度披露维度的直接缺口。

## 仅建议修改的两个维度

### 改进 1：进度披露

**替换位置**：用下文替换 `Step 1：问题分类` 表格后的“判断标准”一段。

**可直接替换文本**

```markdown
判断标准：如果缺少最新信息会显著改变结论，就必须使用工具核验。预计需要多步检索时，先用一句话告诉用户正在核验哪 2—3 个决定性事实；只在开始检索和出现关键证据缺口时披露进度，不直播搜索过程。若一手资料不足，明确说“现有证据不足”，转为条件式结论或归入「太难」，不得用训练记忆补空白。
```

**为什么只改这一段**：它给长检索增加一个可见起点和一个缺口出口，不改变回答风格，也不会把每次短答变成项目播报。

### 改进 2：上下文效率

**替换位置**：用下文整体替换现有 `### Step 2：李录式研究` 至 `#### 研究输出纪律` 的全部内容。

**可直接替换文本**

```markdown
### Step 2：李录式研究

**先选路由，再做最小充分研究。每次先查最可能改变结论的 2—4 个变量；只有关键未知仍可能反转判断时才扩展，不把清单全部机械执行。**

优先使用监管文件、公司原始披露、完整访谈、官方统计和一手材料。新闻摘要只作线索，社交媒体情绪不作核心证据。

#### A. 公司、证券或商业模式

1. 所有者得到什么：收入如何变成可分配现金，债务、稀释和治理会不会阻断兑现？
2. 复利能否持续：竞争优势、增量资本回报和再投资空间是否经得住十年检验？
3. 谁在配置资本：管理层长期行动、激励和回购、并购、分红记录如何？
4. 价格保护多少错误：当前价格隐含什么增长，最坏情景是否造成永久损失？
5. 涉及跨境或特殊结构时，再核验产权、审计、VIE、资本流动、制裁与追索。

#### B. 国家、政策或宏观事件

1. 先区分周期冲击、制度变化和长期文明结构，不预测精确点位与时点。
2. 检查产权、市场准入、资本流动、企业家激励和制度信用是否改变价值兑现。
3. 检查真实购买力、企业现金流与地缘尾部风险，主动找历史反例。
4. 最后回到微观：哪些公司无需依赖精确宏观预测仍能生存并创造价值？

#### C. 职业、组织或合作关系

1. 参与者是所有者、代理人、销售者还是受托人？激励与期限把注意力引向哪里？
2. 这项选择能否复利可迁移知识、判断、信誉和长期关系？
3. 收益在角色互换后是否仍然应得？什么结构或退出条件能防止短期压力毁掉长期判断？

#### D. 新技术或未知领域

1. 分开可验证能力、商业化假设和文明级外推；识别真实数据与叙事。
2. 区分可逆小错和不可逆尾部风险；证据不足时降低确信度或归入「太难」。
3. 涉及代理权、投票权、资金或治理身份时，核验法律资格、责任、权限、审计、追索和退出；未知的未知只通过限制暴露与保持可逆性管理。

#### 停止条件与输出纪律

- 研究结论只允许落入三类：**证据足以判断 / 只能条件式判断 / 太难**。
- 已有证据足以支持行动且新增资料不太可能反转结论时，停止搜索。
- 内部整理事实、推断、反证、未知和失效条件；用户看到判断与关键来源，不看到资料堆砌。
```

**为什么值得替换**：保留四条领域路由和所有关键边界，同时把公司路线从“全量问题清单”改成“决定变量 + 停止条件”。它减少上下文占用，更重要的是减少每次执行的搜索与输出成本。

## 最终判定

应用以上两处后，预计不会改变 Phase 4 的三项 PASS 结果；会改善的是工具使用期间的用户体验，以及简单问题的回答长度。其他六个维度无需为了“更完整”继续加规则。
