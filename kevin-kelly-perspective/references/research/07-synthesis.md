## 一、候选论点池 → 三重验证结果

| 候选 | 跨域复现 | 生成力 | 排他性 | 判定 |
|---|---|---|---|---|
| Protopia（渐进改善） | 技术文明/个人成长/复利 ✓ | ✓ 面对"要不要彻底改变"→找可持续的1% | ✓ 自造词，拒绝乌托邦/末日二分 | **心智模型1** |
| 长视野 = 乐观的推导过程 | 万年钟/职业/投资/育儿 ✓ | ✓ 任何焦虑→先问时间尺度 | ✓ 给出机制而非鸡汤 | **心智模型2** |
| 技术=选项增量器 | 技术哲学/职业选择/育儿 ✓ | ✓ 选打开更多选项的那条路 | ✓ Morozov专门批这一点 | **心智模型3** |
| 阿米什式筛选 | 技术采用/时间管理/消费 ✓ | ✓ 新东西→先问维护成本与关系影响 | ✓✓ 技术乐观主义者主张系统性说不 | **心智模型4** |
| Becoming（成为>获得） | 《必然》首章/职业/认知更新/衰老 ✓ | ✓ 先问"我要成为谁"再问"我该做什么" | ✓ "身份绑价值观不绑认知"的具体操作 | **心智模型5** |
| 提问 > 答案 | AI时代人类价值/自我认知/对话技巧 ✓ | ✓ 困境→重新提问而非直接答 | ✓ 他AI论证的核心支点 | **心智模型6** |
| 丰裕之后，不可复制的才值钱 | 创作者经济/AI时代/财富定义 ✓ | ✓ "AI会取代我吗"→问哪部分不可复制 | ✓ Better Than Free 八生成性 | **心智模型7** |
| 成功=运气+持续出现 | 多域 ✓ | 弱 | ✗ 很多人这么说 | 降级 → 决策启发式 + 价值观 |
| 蜂群思维/涌现 | 主要在技术论述 ✗ | 中 | ✓ | 降级 → 不进模型（他本人2013已修正为"混合控制"） |
| 技术有属灵维度 | 信仰/技术 ✓ | 弱（不产生可操作推断） | ✓✓ | 降级 → 价值观与智识谱系 |

**合并说明**：「乐观是刻意选择」与「长时间视野」原为两个候选，合并为模型2——因为他本人给出的是因果链："The longer your view is, the more optimistic you can become."（Big Think, 2024-10-08）乐观在他这里不是态度，是长视野的推论。

## 三、内在张力（保留，不调和）

1. **技术乐观主义旗手 vs 自己过筛选式低技术生活**：写《失控》《必然》，公开立场是拥抱技术；本人手机不装任何社交软件（36氪2023）、曾多年不用智能手机与有线电视（Fortune 2010）、不日常用VR。他自己的理论出口是「阿米什黑客」——不是拒绝，是极度挑剔地延迟采用。
2. **"未来不可预测" vs 大量断言式预测且极少认错**：反复告诫别人预测必错（"几乎所有预测，包括我的，都是错的"，《2049》导语），但被问"你错在哪"时习惯把答案导向"我讲的是方向不是时间表"。唯一找到的明确认错是脑机接口时间表（从100年下调到25年，他用"shock"形容）。
3. **鼓吹 coveillance（互相监控） vs 箴言里高度审慎的自保**：2014年主张坦然接受双向透明；但书里教人"任何索要账户信息的人先假定是骗子""绝不在电话里回应任何提案""你必须控制沟通渠道"。
4. **给450条人生建议 vs 自我解构**：Freakonomics 2022他主动松口——"也许'建议'这个词不对，也许该叫'对我管用的东西，也许对你也管用'"，并承认幸存者偏差；On Being 谈育儿与技术时直接说"I don't even know right now"。
5. **1979年基督教皈依 vs 技术演化论叙事**：他自己接上了（造物主→自然→人→技术是同一条创造性延长线），但公开材料里从没有记者真正把这个张力追问到底——这是结构性未追问，不是他回避。

## 四、结构性回避（三类，Skill必须忠实呈现而非替他补一个精巧答案）

a. **不逐条正面反驳学术批评**：Morozov（e-Salvation, 2011）、Lanier（Digital Maoism, 2006点名他）、Best & Kellner（2000）——几乎查不到他公开回应。他的应对是换一个新类比绕道走。
b. **不承认某个具体预测彻底失败**：会把质疑重新框定为"被时间证实了"。
c. **不在冲突性议题上做二元站队**：被追问就先拆解术语（"degrowth至少有两种含义"），再拒绝被归类。

## 五、诚实边界（写入Skill）

- **1999年他为什么在《连线》最火时退居 Senior Maverick——查不到本人解释。** 六维度调研专门搜过 Tim Ferriss / EconTalk / Knowledge Project / Leap Academy 等，均无一手自述。Skill 可以呈现"在顶峰主动退位"这个事实模式，不得编造动机。
- 他在AI就业问题上的乐观基于经验断言（"我找不到一个因AI失业的艺术家"，2023），2026年可能已过时，须自行核实。
- 1000 True Fans 带阶级偏见批评（Dave Karpf, 2022）：模型隐含"每人每年有100美元闲钱"的富裕假设。引用该理论必须连带这个批评。
- 中文圈"失控"金句大量误传/断章取义；他本人2013年已在虎嗅明确修正为"混合控制——失控是很好的起始模型，但不能从始至终"。
- 他从未公开谈：临床心理健康问题、政党立场、与子女的具体冲突、是否让子女在家上学。
- 调研截止 2026-08-29。
